# Архивное тестирование Telegram

Запуск: меню «Тестирование → Архив Telegram» в главном окне либо `run_archive.bat`.

Можно сразу передать файлы:

```powershell
.venv\Scripts\python.exe -m src.archive_viewer logs/telegram_monitor1654_2026-09-07_2026-10-07.jsonl logs/telegram_radar_kharkov_2026-09-07_2026-10-07.jsonl
```

Откройте один или несколько архивов JSONL, JSON (включая экспорт Telegram) или CSV. Сообщения сортируются по времени публикации и обрабатываются совместно, при этом контекст, цели и отмены каждого канала независимы.

Каждому каналу соответствует отдельная панель и чат ключевых сообщений. Панель показывает уровень, типы угроз, наличие пуска, направление (на город, на район, от города), приближение (вне города, над городом, над районом), оставшийся срок и совпадение с правилами. Чат содержит исходный текст, время, распознанные признаки, реакцию и изменения состояния. Отмена одного канала не удаляет подтверждения другого.

«Шаг» обрабатывает следующее сообщение. «Воспроизвести» запускает просмотр с выбранным темпом, повторное нажатие ставит паузу. Можно вернуться к началу, перейти к номеру сообщения или к концу. «+60 с» обрабатывает сообщения в следующей минуте и проверяет таймеры. Между постами рассчитываются истечение TTL, выдержки и тихий час. По истечении дополнения выводится причина снятия.

База API, дополнения каналов и итог показаны отдельно. Итоговый уровень — максимальный действующий, типы — объединение действующих угроз. Звуковой профиль выбирается один, по степени и приоритету типа. Telegram может установить тревогу без базы API и не может снизить действующую базу.

По умолчанию архив API не задан. Если исторических данных API нет, они не восстанавливаются автоматически. Для сравнения можно включить отдельный тестовый сценарий: задать общий воздушный уровень, уточняющий тип и его уровень. Сценарий применяется ко всему выбранному архиву; это не история действовавших тревог API.

«Правила теста» меняют конфигурацию только этого окна. Рабочий `config_threats.json` не перезаписывается. После изменения тест начинается заново. «Экспорт CSV» сохраняет время, канал, исходное сообщение, уровни каждого канала, базу, итог, типы, выбранный звук и пояснение. Контрольный прогон локальных архивов: `logs/archive_replay_report.csv`.

Архивное окно работает отдельным процессом, не запускает онлайн-читатели и не подключается к ПЛК. Открытая рабочая программа продолжает свою обычную работу. Исторические часы отображаются в часовом поясе Europe/Kyiv, с учётом переходов на зимнее и летнее время (пакет tzdata из requirements.txt).

**Состояние внедрения:** новая схема подключена к рабочему анализатору. Рабочее и архивное окна используют один парсер Telegram и один расчёт базы и дополнений. У каждого канала в главном окне есть независимое состояние и чат. В ПЛК передаются максимальный уровень и биты всех действующих типов; звуковой профиль остаётся один по степени и приоритету типа. Тихий час и тумблер сохраняют блокировку выдачи. Проверка реального ПЛК автоматически не выполнялась.
