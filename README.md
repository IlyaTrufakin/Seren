# Seren — мониторинг угроз и управление оповещением через Schneider M221

Приложение для Windows на Python/Tkinter получает данные Telegram и AlarmMap API, выбирает тревогу по пользовательским правилам и передаёт параметры оповещения по Modbus TCP.

Актуальная схема: **3 степени опасности × 4 типа угрозы = 12 тревог**, плюс профили отсутствия тревог и потери связи: всего 14 звуков. Правила, источники, приближение, группы дронов и звуковые профили редактируются в конфигураторе. Сначала выбирается степень (критическая → высокая → низкая), затем тип (ракета → бомба → дрон → неопознанная). API: уточняющий тип имеет приоритет над общей воздушной тревогой; без уточнения только air/3 считается ракетной угрозой, air/1–2 — дроновой. Главное окно показывает базу API, независимые состояния и чаты каналов, объединённый итог и причины изменений. Все действующие типы сохраняются; приоритет типа выбирает один звуковой профиль.

# TM221 Modbus TCP Gateway (Windows 10/11)

Программное обеспечение с графическим интерфейсом для обмена данными между ПК под управлением Windows 10/11 и программируемым логическим контроллером (ПЛК) **Schneider Electric Modicon M221 (TM221CE16R)** по протоколу **Modbus TCP**.

---

## 🚀 Назначение и возможности

- **Сетевое подключение**:
  - Настройка IP-адреса контроллера (по умолчанию `192.168.0.221`) и порта (по умолчанию `502`).
  - Настройка Modbus Unit ID / Slave ID (для M221 по умолчанию `255` или `1`).
  - Настройка периода циклического опроса (мс) и таймаута связи.
  - Автоматическое переподключение при разрыве сетевого кабеля / перезагрузке ПЛК.
  - Кнопка быстрой проверки доступности порта и времени отклика («Проверить пинг»).

- **Двусторонний обмен 16-битными словами (%MW)**:
  - **Передача в ПЛК (%MW0)**:
    - Ввод значения в десятичном формате (DEC 0..65535) или шестнадцатеричном (HEX 0x0000..0xFFFF).
    - 16 интерактивных кнопок бит (0..15): прямое переключение битов кликом мыши (с автоматическим пересчетом числа).
    - Режимы отправки:
      - Ручная отправка по кнопке («Отправить ➔»).
      - Автоматическая отправка при любом изменении значения или переключении бита.
      - Непрерывная циклическая отправка в каждом такте опроса.
    - Быстрые кнопки: `0x0000`, `0xFFFF`, `+1`, `-1`.
  - **Прием из ПЛК (%MW1)**:
    - Крупное табло отображения принятого слова:
      - Беззнаковое число (DEC Unsigned: 0..65535).
      - Знаковое число (DEC Signed: -32768..32767).
      - Шестнадцатеричное число (HEX).
      - Двоичный вид (BIN с разделением по тетрадам).
    - Светодиодная индикация всех 16 битов (зеленый — 1, темный — 0).
    - Штамп времени последнего успешного чтения с точностью до миллисекунд и задержка отклика (RTT).

- **Диагностика и статистика**:
  - Цветной индикатор статуса соединения (Зеленый = На связи, Желтый = Подключение, Красный = Отключено).
  - Подсчет общего количества запросов, успешных циклов и ошибок.
  - Измерение задержки отклика (RTT в мс).
  - Детализированный журнал событий с метками времени и автопрокруткой.

- **Сохранение конфигурации**:
  - Все сетевые параметры и адреса регистров сохраняются в файл `config.json` и восстанавливаются при следующем запуске.

## ⚙️ Настройка в среде разработки ПЛК (EcoStruxure Machine Expert - Basic / SoMachine Basic)

1. **Ethernet конфигурация ПЛК**:
   - IP-адрес: `192.168.0.221`
   - Маска подсети: `255.255.255.0`
   - Modbus TCP сервер включен (по умолчанию активен на порту 502).
2. **Адресация регистров Schneider M221**:
   - `%MW0` соответствует Modbus Holding Register с адресом `0` (в 0-based адресации) или `40001` (в 1-based адресации).
   - `%MW1` соответствует Modbus Holding Register с адресом `1` (или `40002`).
   - Если программа в ПЛК должна видеть передаваемое с ПК значение, используйте в логике контроллера слово `%MW0`.
   - Если ПЛК должен передавать значение на ПК, записывайте результат в слово `%MW1`.
