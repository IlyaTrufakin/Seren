# Независимый radar_kharkov — наблюдение

Второй анализатор создан 2026-10-12. Запуск `run_radar_kharkov.bat`: отдельное окно, графики, сообщения и причины, собственный файловый журнал. Анализатор использует тот же движок, что monitor1654, с отдельными настройками в `profiles/radar_kharkov/config.json`.

## Изоляция

Передача в основной модуль отключена: `publish_to_main=false` в профиле и дополнительный параметр `--no-publish` в запуске. Поток отправки не создаётся, HTTP-запросов в основное приложение нет, ключ IPC не читается. В списке источников `config_analyzers.json` остаётся только monitor1654. ПЛК и API этому анализатору не нужны. В окне явно показано «НАБЛЮДЕНИЕ — передача в основное приложение отключена».

Отдельный супервизор восстанавливает только radar_kharkov при аварии/зависании. При обычном закрытии окна он не открывает его снова. Для повторного открытия снова запустите `run_radar_kharkov.bat`. Если окно уже работает, повторный запуск показывает его; если оно закрыто, супервизор открывает его по явному запросу. Новая задача автозапуска Windows для radar_kharkov не устанавливалась; существующий автозапуск основных приложений не менялся.

За основу взят актуальный настроенный monitor1654, включая четыре выходных состояния 0/1/2/4, ракеты/Бандероль, КАБ, группы дронов, неизвестную цель как ракету, контекст 30 минут и TTL 10 минут. По сообщениям radar_kharkov добавлены русские варианты движения, предупреждений, отмены и падения, написания городских ориентиров и дальних населённых пунктов.
